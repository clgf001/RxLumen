## 已处理的问题

- Prisma 6 在 Windows 首次部署不存在的 SQLite 文件时可能返回空泛的 Schema engine error；迁移脚本现在先创建目录与空文件，再迁移，不覆盖已存在数据库。
- Prisma CLI 的传递依赖 deepmerge-ts 存在已知问题；覆盖至 8.0.0 后重新执行安装、迁移、类型检查、测试及构建，审计归零。参考 [GHSA-ggr8-5vv4-36mx](https://github.com/advisories/GHSA-ggr8-5vv4-36mx)。
- 避开本机现有系统端口，开发前端采用 5178，后端采用 3100。
- 按 Ant Design 6 接口更新过时属性，并限制长说明书编辑表单的滚动区域。
